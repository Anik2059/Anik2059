## 👋 About Me

I'm **Md. Hasibul Islam Anik**, a Computer Science and Engineering student at **Green University of Bangladesh**. I learn by building: from interactive web interfaces to Python desktop applications and networking simulations.

I care about understanding how software works—not just making it look good. I'm strengthening my development fundamentals while exploring **Web3, smart contracts, and AI/LLM applications**.

- 🧩 **Software development:** turning ideas into useful, understandable applications.
- 🐍 **Python & systems:** desktop interfaces, sockets, and client–server communication.
- 🌐 **Web development:** building interactive experiences with HTML, CSS, and JavaScript.
- ⛓️ **Web3:** learning Ethereum, Solidity, and Ethers.js fundamentals.
- 🤖 **AI:** exploring how LLM-powered applications and developer tools are built.
